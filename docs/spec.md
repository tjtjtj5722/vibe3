# 자동차 다이렉트 안내 서비스 MVP 기획서

> 문서 상태: 초안 0.2  
> 작성일: 2026-09-07  
> 전제: 서비스 설명이 입력되지 않아 현재 프로젝트의 랜딩 페이지를 기준으로 작성했으며, 핵심 목적과 등록·로그인 방식은 사용자 답변으로 확정했다.

## 1. 서비스 정의

### 한 줄 정의

자동차 다이렉트 보험의 장점과 선택 기준을 쉬운 말로 안내하고, 상담·견적 요청을 받아 상담 고객으로 연결하는 모바일 중심 서비스.

### 주 사용자

- 25~60대 자동차 보유자 또는 자동차 보험 갱신 예정자
- 설계사를 통하지 않고 다이렉트 보험을 알아보고 싶지만 용어나 비교 기준이 어려운 사용자
- 휴대폰에서 짧은 시간 안에 핵심 정보를 확인하고 다음 행동을 결정하려는 사용자

### 해결하려는 문제

1. 다이렉트 보험의 장점과 주의점을 처음 알아보는 사용자가 이해하기 어렵다.
2. 여러 정보를 찾아다녀야 해서 무엇을 기준으로 비교해야 하는지 판단하기 어렵다.
3. 관심 있는 정보를 다시 찾거나 문의 내용을 관리하기 어렵다.

### MVP 목표

- 사용자가 첫 방문 후 3분 안에 다이렉트 보험의 핵심 장점과 비교 기준을 이해한다.
- 관심 콘텐츠를 저장하거나 상담·견적 요청을 한 번의 흐름으로 완료한다.
- 상담·견적 요청의 접수량과 완료율을 통해 상담 고객 확보 가능성을 검증한다.
- 실제 보험료 자동 산출이나 계약 체결은 제공하지 않는다.

## 2. 화면 목록

| 화면 | 목적 | 핵심 구성 | 주요 행동 |
|---|---|---|---|
| 첫화면 | 서비스의 가치와 이용 방법을 빠르게 전달 | 히어로 GIF, 한 줄 소개, 장점 3개, 추천 콘텐츠, 둘러보기 버튼 | 목록으로 이동, 로그인, 상담 요청 시작 |
| 목록 | 다이렉트 보험 관련 정보를 주제별로 탐색 | 검색, 카테고리 필터, 콘텐츠 카드, 최신순 정렬 | 검색, 필터 선택, 상세 열기, 저장 |
| 상세 | 한 콘텐츠를 이해하고 다음 행동을 선택 | 제목, 요약, 본문, 출처, 최종 수정일, 관련 콘텐츠 | 저장, 목록으로 돌아가기, 상담 요청 이동 |
| 등록 | 자동차 보험 상담 요청 또는 견적 요청 접수 | 요청 유형, 차량 유형, 보험 만료 예정일, 궁금한 내용, 연락 방법, 개인정보 동의 | 유형 선택, 임시 입력, 제출, 완료 확인 |
| 로그인 | 저장 목록과 요청 내역을 사용자에게 연결 | 카카오 로그인, 휴대전화 번호 인증, 오류 안내 | 카카오 로그인, 휴대전화 인증, 회원가입 동의 |
| 마이페이지 | 개인 정보와 서비스 이용 기록 관리 | 기본 정보, 저장한 콘텐츠, 상담 요청 상태, 로그아웃 | 저장 취소, 요청 확인·취소, 정보 수정, 로그아웃 |

### 핵심 사용자 흐름

1. 첫화면에서 서비스 내용을 확인한다.
2. `둘러보기`를 눌러 목록으로 이동한다.
3. 관심 콘텐츠의 상세 내용을 읽는다.
4. 저장이 필요하면 로그인한 뒤 콘텐츠를 저장한다.
5. 추가 안내가 필요하면 등록 화면에서 상담 요청 또는 견적 요청을 선택해 제출한다.
6. 마이페이지에서 저장 콘텐츠와 요청 처리 상태를 확인한다.

### 공통 상태

- 로딩: 콘텐츠 카드 또는 본문 영역에 간단한 로딩 표시
- 빈 상태: 검색 결과, 저장 목록, 요청 내역이 없을 때 다음 행동 안내
- 오류: 원인과 재시도 방법을 쉬운 문장으로 표시
- 성공: 저장, 등록, 취소가 완료되면 화면 안에서 즉시 확인 가능하게 표시

## 3. 저장해야 할 데이터

개인정보는 MVP에 필요한 최소 범위만 저장한다. 실제 보험 계약 정보, 주민등록번호, 결제 정보는 저장하지 않는다.

| 구분 | 항목 | 형식 | 필수 | 설명 |
|---|---|---|---|---|

| 사용자 | 휴대전화 번호 | E.164 문자열, 예: `+821012345678` | 조건부 | 휴대전화 로그인 또는 연락 선택 시 필요하며 중복 불가 |

### 데이터 관계

- 사용자 1명은 콘텐츠 여러 개를 저장할 수 있다.
- 콘텐츠 1개는 여러 사용자에게 저장될 수 있다.
- 사용자 1명은 상담 요청을 여러 건 등록할 수 있다.
- 사용자가 탈퇴하면 법적 보관 의무가 없는 저장 기록은 삭제하고, 상담 요청은 정해진 보관 정책에 따라 삭제 또는 비식별화한다.

## 4. 이번 과정에서 만들지 않을 기능

- 보험사별 실시간 보험료 계산 및 견적 비교
- 보험 가입, 계약 체결, 전자서명, 보험료 결제
- 사용자 상황을 분석한 보험 상품 자동 추천
- 주민등록번호, 운전면허번호, 차량번호 등 고위험 개인정보 수집
- 사고 접수, 보험금 청구, 증빙 서류 업로드
- 보험사 또는 외부 비교 플랫폼 API 연동
- AI 챗봇 또는 실시간 상담 채팅
- 카카오 외 기타 소셜 로그인, 2단계 인증, 생체 인증
- 푸시 알림, 문자 자동 발송, 이메일 마케팅 자동화
- 후기, 댓글, 좋아요, 사용자 간 메시지 기능
- 다국어 지원과 네이티브 모바일 앱
- 고급 관리자 통계, 광고 관리, 콘텐츠 자동 생성

## 5. 운영 및 콘텐츠 원칙

- 보험 정보는 일반적인 안내임을 명확히 표시하고 개별 가입 권유로 오해되지 않게 한다.
- 콘텐츠마다 출처와 최종 수정일을 표시한다.
- 가격, 법률, 약관처럼 변경될 수 있는 정보는 게시 전과 정기 점검 시 다시 확인한다.
- 25~60대 사용자가 이해하기 쉬운 짧은 문장과 충분한 글자 크기를 사용한다.
- 상담 요청 제출 전 개인정보 수집 목적, 보관 기간, 철회 방법을 안내한다.

## 6. MVP 완료 기준

- 필수 6개 화면이 모바일과 데스크톱에서 이용 가능하다.
- 목록 검색·필터와 상세 조회가 동작한다.
- 카카오 로그인·휴대전화 인증 로그인·로그아웃이 동작한다.
- 콘텐츠 저장 및 저장 취소가 동작한다.
- 상담·견적 요청 등록과 마이페이지 내 유형·상태 확인 및 취소가 동작한다.
- 로딩·빈 상태·오류·성공 상태가 각 핵심 흐름에 포함된다.
- 개인정보 동의 이력과 콘텐츠 출처·수정일이 저장되고 표시된다.

## 7. 확정된 결정

1. 서비스의 핵심 목적은 `상담 고객 확보`다.
2. 등록 화면은 `상담 요청`과 `견적 요청`을 모두 제공한다.
3. 로그인은 `카카오 로그인`과 `휴대전화 번호 인증`을 우선 제공한다.
